Cintra GPL

A tiny educational programming language whose interpreter is written in Python.

1. What is Cintra GPL?

Cintra GPL is a small "general purpose language" that you write line by line in a plain text file. The interpreter (the file Cintra GPL python interpreter.txt) is a single Python script. It reads your program one line at a time, looks at the first word of the line, and decides what to do.

The most important thing to understand: almost every expression in Cintra is evaluated by Python's eval(). That means anything Python can evaluate — 2 + 2, "a" + "b", len("hello"), str(42) — works inside Cintra expressions.

Every keyword exists in two forms: English and Russian. They do exactly the same thing. You can even mix them in one program.

2. How to run a program

  1. Save the interpreter as a Python file (for example cintra.py).
  2. Write your program in a separate text file (for example hello.cintra).
  3. Run the interpreter with Python 3:
python cintra.py
Enter file name: hello.cintra

The interpreter asks for the file name, then runs the program. When the file ends normally it prints: 

Program have been done with exit code 0.

3. Hello, world

Create a file with one line:

out "Hello, world!"

Output:

Hello, world!

out evaluates everything after it as a Python expression and prints the result. Quotes are required for text, because the text is evaluated as a Python string.

Assignment operators

A line can also be a plain assignment. The name comes first, then the operator, then the expression:

x = 5
x += 1
x -= 2
x *= 3
x /= 4
x //= 2
x %= 3
x **= 2

5. Variables

All variables live in one global Python dictionary called stack. There is no scoping, no let, no types — just names and Python values. 

var x = 10
var name = "Alice"
var flag = True

out x
out name
out flag

Output:

10
Alice
True

The var command ignores the third word, so var x = 10 and var x 10 behave the same way. Use the = form for readability.

6. Input

out "What is your name?"
in name
out "Hello, " + name

Session:

What is your name?
Bob
Hello, Bob

Important rule about numbers

in always reads a string, unless the variable already exists. If the variable already exists, the interpreter converts the input to the same type as the old value.

So if you want to read a number, declare it first:

var age = 0
in age
out age + 1

Here var age = 0 makes age an int, so the input "20" is converted with int("20") and the program prints 21.

If you forget the declaration, age becomes a string and age + 1 will fail.

7. Conditions

var age = 0
in age

if age >= 18:
    out "You are an adult."
else:
    out "You are a minor."
endif

Notes:

  • The colon at the end of if and while is optional — it is stripped away.
  • Indentation is only for humans. The interpreter uses endif to know where the block ends.
  • && is translated to Python and, and || to or.
var a = 5
var b = 10

if a > 0 && b > 0:
    out "both positive"
endif

Because conditions are evaluated by Python, you can also use not, comparisons, and any function available in Python.

8. Loops

var i = 1

while i <= 5:
    out i
    i += 1
whileend

out "Finished!"

Output:

1
2
3
4
5
Finished!

Loops can be nested. The interpreter counts while / whileend pairs to find the matching end of the block. 

var i = 1

while i <= 3:
    var j = 1
    while j <= 3:
        out i * j
        j += 1
    whileend
    i += 1
whileend

9. Functions

Functions are defined with lambda and called with call.

lambda greet name : out "Hello, " + name
call greet "World"

Output:

Hello, World

The part before the colon is the function name followed by its parameters. The part after the colon is the body. The body is translated into a Python statement — in practice out, in or out_type. 

lambda add a b : out a + b
call add 3 4

Output:

7

Arguments are evaluated before the call, so string arguments need quotes: call greet "Ann".

10. Types

out_type 5
out_type "hello"
out_type 3.14

Output:

<class 'int'>
<class 'str'>
<class 'float'>

This is useful for debugging when you are not sure whether in gave you a string or a number.

11. Comments

// This line is ignored
out "Visible line"
// out "This one is not executed"

A comment must be a whole line that starts with //. You cannot put a comment at the end of a line of code.

12. Modules

include math

include runs a Python import. Note that the module is not added to the variable stack, so you cannot write math.sqrt(9) afterwards. In the current version this command is mostly useful for modules that have side effects on import.

13. A complete example program

// guess.cintra
// A small program that prints a multiplication table

var size = 0
out "Table size?"
in size

var i = 1
while i <= size:
    var j = 1
    while j <= size:
        out i * j
        j += 1
    whileend
    out "---"
    i += 1
whileend

out "Done!"

14. Known quirks and limitations

  • Undeclared numeric input. in x on a fresh name stores a string. Declare it first with var x = 0 if you need a number.
  • No-argument calls are unreliable. call name with no arguments evaluates the call and then tries to execute the returned value as code. It only works when the function returns None.
  • return is not usable. It exists in the source but is marked as unfinished and does not work as expected.
  • Blocks use keywords, not indentation. Every if needs an endif, every while needs a whileend.
  • No for loop. Use while with a counter.
  • Bad conditions stop the program. If a condition cannot be evaluated, the interpreter prints BAD CONDITION on line N and stops.
  • Errors inside out and call are not caught and will crash the interpreter with a Python traceback.
  • One expression per line. The language is line-oriented; everything is split on whitespace first.

15. Summary

Cintra GPL is a small language built on top of Python's eval(). Its whole idea is:

  1. Read a line.
  2. Look at the first word.
  3. If it is a keyword, do the keyword's job.
  4. Otherwise, treat the line as a Python expression and evaluate it.

That is why it is a good learning project: the interpreter is short, the rules are simple, and you can extend it with new keywords in a few lines of Python.
